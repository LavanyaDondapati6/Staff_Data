Employee Hub – Power BI Dashboard
 Project Overview

The Employee Hub is an interactive Power BI dashboard designed to analyses employee information, salary distribution, employee types, work locations, gender, departments, and Full-Time Equivalent (FTE) data. The dashboard provides a centralized view of workforce information and transforms raw employee data into meaningful visual insights.

The main objective of this project is to create an easy-to-understand business intelligence dashboard that helps users explore employee-related data and identify important patterns and trends.

 Key Features
Total Salary KPI: Displays the overall salary amount across employees.
Maximum Salary KPI: Shows the highest salary value in the dataset.
Salary by Employee Type: Compares salary distribution across Permanent, Temporary, and Fixed-Term employees.
Salary by Gender: Provides a comparison of salary between different genders.
FTE by Employee: Displays the Full-Time Equivalent value for individual employees.
FTE by Department: Analysis FTE distribution across different departments.
Work Location Analysis: Uses an interactive map to visualize employee locations.
Interactive Filters: Allows users to filter the dashboard based on different work locations.
Interactive Visualizations: Includes bar charts, donut charts, KPI cards, line charts, and map visualizations.

 Key Insights

The dashboard makes it easier to understand how salaries are distributed among different employee types and genders. It also provides insights into employee FTE across departments and individual employees. The work-location visualization helps users understand the geographical distribution of the workforce.

 Learning Outcomes

Through this project, I developed practical skills in data preparation, Power Query transformations, DAX calculations, dashboard design, KPI creation, data visualization, and business intelligence reporting. I also learned how to present complex employee data in a simple and interactive format.

 Project Goal

The goal of the Employee Hub dashboard is to provide an interactive reporting solution that can support workforce analysis and help organizations make more informed, data-driven decisions.
